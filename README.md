# python-projects
A collection of Python projects developed as part of my programming learning journey.
These projects focus on practicing fundamental Python concepts, problem-solving, and building simple console-based applications.

Projects
1. Calculator:
A simple calculator that performs basic arithmetic operations.

2. Number Guessing Game:
A game in which the computer selects a random number and the user tries to guess it.

3. Login System:
A basic login and registration program for practicing user authentication concepts.

4. Phonebook:
A simple contact management application that allows users to store, search, and manage contacts.

5. Quiz Application:
A console-based quiz program that presents questions, receives user answers, and calculates the score.

6. Rock Paper Scissors:
A classic game where the user plays against the computer.

7. Shopping List:
A simple application for managing a shopping list.

8. Student Grade Management System:
A program for managing student information and grades, including calculating averages and searching for records.

How to Run

Make sure Python 3 is installed on your computer.
Clone or download this repository.
Open the project folder.
Run any project individually using Python.

Example

python Calculator.py
For the Quiz Application, keep question.py in the same directory as Quiz.py.
